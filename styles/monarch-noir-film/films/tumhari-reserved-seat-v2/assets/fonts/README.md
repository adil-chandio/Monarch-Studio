# Embedded production fonts

- `Montserrat-VF.ttf` — Montserrat variable font, SIL Open Font License 1.1; license in `Montserrat-OFL.txt`; upstream: <https://github.com/google/fonts/tree/main/ofl/montserrat>.
- `PermanentMarker.ttf` — Permanent Marker, Apache License 2.0; license in `PermanentMarker-APACHE-2.0.txt`; upstream: <https://github.com/google/fonts/tree/main/apache/permanentmarker>.

These byte-identical copies make the package self-contained and preserve typography across rebuilds.
