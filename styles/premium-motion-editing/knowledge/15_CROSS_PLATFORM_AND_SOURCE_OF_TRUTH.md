# 15 · Cross-platform organization and source of truth

## Roles

**Repository/GitHub:** versioned code, policy, prompts, templates, exact small source and tests. **Drive:** original reference, masters, full source/recovery bundles and readable exports. **Google Docs:** portable comprehensive human hub/codex. **Notion:** browsable project knowledge, policy callouts and the Workflows registry row. **Linear:** permanent resume pointer, finite task/acceptance status and cross-links.

The local code/policy contract and the Notion registry's discoverability role must not drift. The latest explicit user feedback overrides an old experimental preset. Link each platform to the others and to the exact same WF-05 identity. Do not rename or overwrite unrelated workflows.

## Publication transaction

Finish local source and tests → create checkpoint → publish the tracked working branch → verify remote/CI → publish or update readable hubs and source bundles → retrieve metadata/content to verify → write each target's real ID/result into its own receipt. Where the user's goal is new-chat default access, make the main-branch status explicit; an unmerged branch is not silently called main publication.

Never invent a connector ID or mark every platform complete because one upload succeeded. Keep pending/failed targets explicit. Do not collect credentials in chat or store connector tokens in the repository. Do not broaden sharing permissions merely to simplify a workflow.

## Mirrors and exact recovery

Readable mirrors link to the full canonical source rather than pretending every code file is an inline Notion paragraph. The source inventory lists each preserved case file and hash. Full media remain external by exact ID/hash; package and registry links are verified. Regenerate readable exports after policy changes so the old V6 pill instructions do not outrank the new rule.

The foundation's final coverage report states what is present, what was tested, which platforms were verified and what historical evidence was unavailable. That is the honest meaning of comprehensive: no silent gaps and no invented memories.
