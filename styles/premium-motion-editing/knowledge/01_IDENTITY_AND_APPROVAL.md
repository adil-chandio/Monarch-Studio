# 01 · Identity, approval and the quality contract

## One style, one identity

**WF-05 · Premium Motion Editing** is a distinct permanent style in Monarch Studio. Its stable repository identity is `premium-motion-editing`; its entry command is `MOTIONGO <topic or reference>`. `WF-05`, `WF5` and the full name are aliases, not new workflows. The existing user-created Drive folder is reused. Do not create another WF-05 merely because a new chat starts.

The style is an editorial motion argument: ideas become tangible subjects, objects and relationships; those objects actually change over time; concise kinetic type directs attention; voice determines the semantic edit; restrained sound accents make actions feel intentional. A busy filter stack is not the definition of premium.

## Binding user decision — 15 October 2026

The user approved the V5-level clean direction and the non-caption improvements made in V6, but explicitly called V6's **lower caption treatment** bad. This is a component-level decision, not a rejection of every V6 improvement and not permission to keep the pill strip because technical tests passed.

The production default therefore combines:

- V5-like clean composition and integrated editorial hierarchy;
- accepted V6 near/far depth motion, perspective/extruded title entrances, short transition grammar and sound accents;
- **no V6 bottom caption pills and no active-word lower strip**;
- optional separate SRT for accessibility; plain V5-like subtitle text only when the brief explicitly requests it.

“Bottom captions rejected” does **not** ban an integrated headline placed below the subject. `BHAAG NAHI`, `AI SHORTCUTS`, `MUSCLES` and a closing question can belong in the lower part of a deliberate composition. The rejected thing is the separate recurring sentence-pill UI competing with that composition.

`data/approved-profile.json` is the machine-readable decision. `records/USER_REQUEST_20261015.txt` preserves the exact visible request. If historical V6 code disagrees, the latest policy wins. Originals remain unchanged as evidence. A new full-length combined-policy master was **not** rendered as part of this foundation; do not label V6 itself the fully approved default.

## Acceptance is not a slogan

A future project must demonstrate actual motion, readable hierarchy, correct meaning, safe subject edges, voice/picture alignment, clean branding, decodable export and recoverable delivery. The foundation preserves a tested reference level and executable guards; it cannot guarantee every future model output will be perfect. Reuse the production grammar, not the old Einstein story for an unrelated topic.

## Separation from the rest of the studio

WF-01's stickman/SHADE engine, WF-03's noir world, WF-04's locked personal hero and other folders remain separate. Do not import a Monarch face, crown finale, logo or unrelated workflow trigger by habit. Shared assets require explicit casting and appropriate rights. A folder visible in Drive does not prove that its full implementation exists in this checkout.
