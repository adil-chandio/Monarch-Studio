# 14 · New-chat operating contract and response behavior

## Minimum reading order

1. Repository `AGENTS.md` and `continuity.py resume`.
2. WF-05 `FRESH_CHAT.md`, `README.md` and `data/approved-profile.json`.
3. `RESUME_STATE.md` and `data/links.json` for the latest policy and real destinations.
4. The V5 reference, accepted V6 facets and case shot map; inspect actual media when producing a new edit.
5. Relevant technical chapters and lessons before modifying that component.

Do not require the user to paste the whole history again. If the repository is not connected to a future chat, a trigger word alone cannot grant access: provide the linked hub/recovery package as the entry point. Never promise magical memory across disconnected services.

## What MOTIONGO means

For a genuine new topic/reference: resume first, establish one active task, read the current policy, inspect sources, plan the argument/metaphors, create matching narration/assets, prototype, render, QA, present, upload/verify and archive. Voice/tool-required selection or a real missing permission is a legitimate pause; trivial repeated design approval is not.

For an active revision: retain successful clips, selected speech and reference; change only the requested components. For a completed task followed by a bare continue: show the verified deliverable and clarify a new revision only if needed. Never treat a completed project as an unfinished render because a stale chat summary says otherwise.

## User-facing communication

Use concise natural Roman Urdu when replying to this user. State concrete progress, not repeated empty promises. Do not blame the user for service interruptions. Do not announce completion until the files/IDs/hashes exist. On a real blocker, say exactly which stage is blocked, what remains intact and what input/action is needed.

A completed response should lead with the actual video or requested knowledge artifact, then its viewing/download link, the material changes, the export identity and recovery status. Distinguish “2.5D/3D-style” from new 3D geometry. Do not claim browser playback was personally tested if only decoding/metadata were tested; provide a download fallback while Drive processes previews.

## Keeping the level consistent

Quality comes from repeatedly executing the brief, source inspection, metaphor logic, motion plan, hierarchy and QA—not from copying a celebratory adjective. The approved profile and tests stop specific regressions; creative review stops more subtle ones. Store every new accepted lesson in this named style so the next chat starts from accumulated evidence rather than from zero.
