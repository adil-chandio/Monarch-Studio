# Studio layer

This directory contains cross-workflow governance and concept memory:

- `registry.json` — normalized machine-readable workflow/vendor/character registry;
- `RESUME_STATE.md` — imported studio state record;
- `editor-brain/` — current cross-workflow concept memory (v2.2 / registry generation 3);
- `workflow-template/` — historical template/scaffold reference;
- `MONARCH_STUDIO_REGISTRY.md` and kickoff prompt — imported governance records.

Historical records are preserved. Normalized operational decisions live in `registry.json` and `docs/RECONCILIATION.md`.
