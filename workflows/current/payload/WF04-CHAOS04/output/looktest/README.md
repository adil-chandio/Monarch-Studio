Rendered on GitHub's Ubuntu runner with the Blender 4.2 `bpy` wheel —
CPU only, 360 × 640, 8 samples, denoised. Not the delivery master; this
exists so the character, sets and motion can be reviewed without the GPU box.

- `looktest_clip.mp4` — shots 05–06 contiguous, with the real score
- `progress_*.jsonl` — per-frame seconds, so the full render's ETA is measured
- `frames/` — the still PNGs
- `chaos04.manifest.json` — segment map that produced this
